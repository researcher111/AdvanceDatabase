# Guides for agents

Read these files when revising lecture writing, slide explanations, presenter notes, or teaching videos in this repository.

Start with [Explain complex ideas with CLEAR](clear-explanations.md). It includes Calibrate, Link, Envision, Abstract, and Repeat, a practical writing workflow, a reusable template for another video, and applications across Lectures 11–15 and Labs 9–11. Use [Storytelling for technical lectures](lecture-storytelling.md) to give the lesson a concrete task, visible actions, and a causal sequence.

## Applying the guides

Check the audience’s prior knowledge, map a familiar comparison to the actual mechanism, show a small worked example before its general formula, and revisit the same model at the end. Keep invented scenes, toy inputs, estimates, and measurements distinguishable. Preserve stable scene IDs, timing, controls, source links, and the course’s technical examples unless the task requires changing them.

For a new video, use the template in the CLEAR guide. Save its source metadata, timestamped ideas, and the application to the current topic. Read the guides explicitly in future chats; the files provide persistent context independently of chat memory.
