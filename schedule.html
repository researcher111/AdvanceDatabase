Advanced Databases for Data Science · DS 6XXX · Daniel G. Graham, UVA School of Data Science

This course opens with the question a data-science curriculum usually skips: what is actually happening underneath the query? It answers that the hard way: you build a working relational database engine from scratch, in Python. microdb, built in the spirit of Edward Sciore's SimpleDB, grows one subsystem per week: pages on disk, a buffer pool, records and a catalog, query operators, a SQL front end, a B+ tree, and transactions. After the midterm the lens widens to the engines data scientists live in: DuckDB and the columnar world, vector databases, MapReduce, Spark & Ray, Google's Bigtable, and graph databases. The semester project has your team build a retrieval-augmented-generation (RAG) pipeline in Python on top of the same ideas.

Weekly rhythm. Lecture Tuesdays: concepts, live demos, and a 10-minute quiz on the prior week at the start of class. Lab Thursdays: 75 minutes, laptop open, building; whatever isn't finished in class is homework, due the following Thursday. The midterm lands Thursday Oct 22, after the microdb core closes; the final session (Tue Dec 8) is project presentations. Two breaks fall in the window: fall Reading Days (no class Tue Oct 6) and Thanksgiving recess (no class Thu Nov 26).
