# Writing teaching material

Before creating or revising teaching material, read [the CLEAR guide](<guide for agents/clear-explanations.md>).
Use CLEAR to organize the explanation. Apply its ASD-STE100 style rules to the wording.
These are the default writing rules for this repository unless the user requests a different style.

Apply these rules to lecture readings, slides, presenter notes, labs, interactive explanations, reviews, and discovery sessions.
Use [the storytelling guide](<guide for agents/lecture-storytelling.md>) when a concrete scene helps explain the mechanism.

Preserve technical meaning, code, formulas, measurements, source quotations, and assignment requirements.
Keep required and optional work distinct. Follow the preservation and review checks in the CLEAR guide.
